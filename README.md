# Photocan Bodas

Sitio estático de bodas de Photocan: landing en un solo `index.html`.

## Publicar

No requiere instalación ni compilación. Publica la raíz del repositorio en cualquier hosting estático.

## Cambiar el WhatsApp

Edita la constante `WHATSAPP` en el script `#app` de `index.html`, con lada.
